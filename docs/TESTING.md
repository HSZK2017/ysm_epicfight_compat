# 测试与游戏内验收

## 自动测试的边界

运行 `./gradlew.bat clean build` 后，`./scripts/summarize-tests.ps1` 会列出实际执行数和各测试类的跳过数。CI 也在构建摘要中显示这些数字。没有本地模型、游戏安装或分支源码时，相关用例按条件跳过；不要为了减少跳过数而把第三方模型加入仓库。

缓存回归测试使用临时网格、运行时文件和纹理字节，覆盖清单生成、逐项校验、同长度损坏、文件缺失及过期文件清理。延迟释放测试覆盖到期释放、重新排队与重载时立即释放。`PivotRuleCorpusSweepTest`、`NeckRuleCorpusSweepTest` 和 `ShoeLegStaticAuditTest` 是对私有样本库的测量工具，报告中的候选规则差异不是预设的通过阈值；几何不变量由独立的断言测试验证。

升级 OpenYSM 或 ModernYSM 时，在本机提供相应源码，运行 README 中的 `MixinTargetSignatureTest` 命令。官方 YSM JAR 的目标检查在默认构建中执行。

## 游戏内验收矩阵

以下项目依赖实际渲染、外部模组或私人模型；每次修改渲染、模型缓存、动画或物理状态后，至少运行受改动影响的行。记录游戏版本、YSM 分支、Epic Fight 版本、模组版本及结果；截图、录像和模型包留在本机。

| 场景 | 操作 | 应观察到的结果 |
| --- | --- | --- |
| 初次转换与缓存恢复 | 选中同一模型，第一次进入战斗模式；重启游戏后再次进入 | 转换完成后网格、贴图和动画一致；重启后可从缓存恢复 |
| 资源重载与淘汰 | 在 `lazyModelCacheSize=8` 下轮流加载超过 8 个模型，再切回第一个并执行 `F3+T` | 已淘汰模型可重新加载；无长期缺贴图、消失网格或重复渲染 |
| 条件形态残影 | 使用 Nightfall 或 DevilMineCraft 的阎魔刀触发闪避瞬身；选择含多种条件形态的模型 | 残影只显示创建瞬间实际可见的形态，不叠加所有形态 |
| 大幅奔跑的裙摆 | 使用 `wine_fox/01_taisho_maid` 在 EF 战斗模式持续奔跑、转向、停下 | 裙片保持近似整体；允许瞬时局部穿模，不应持续散成布条或脱离身体 |
| 连续尾巴 | 使用带分段尾巴的模型奔跑、急停和转身 | 尾尖到尾根保持连续，不出现尖端独自运动 |
| 实体及世界隔离 | 让两个实体使用同一模型，再切换存档或世界并重新生成同 UUID 的实体 | 各实体独立模拟；新世界不继承旧世界的摆动状态 |
| YSM 分支与警告 | 分别使用官方 YSM、OpenYSM、ModernYSM 启动并进入战斗模式 | 兼容分支的渲染和输入正常；旧的 YSM×EF 兼容警告不再出现，其他警告仍可见 |

模型素材只用于本地验收。仓库和 CI 不保存 `.ysm`、模型贴图、转换产物或从这些素材摘录的样本。
